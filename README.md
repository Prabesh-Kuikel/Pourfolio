# Pourfolio — GitHub Pages package

This ZIP is a ready-to-publish static site. Upload its contents—`index.html`, `assets/`, and `atlas/`—to the root of a GitHub repository. Keep `atlas/` beside the main page.

## Publish
1. Upload and commit every archive entry to the repository root.
2. In GitHub, open **Settings → Pages**.
3. Select **Deploy from a branch**, choose the branch and `/(root)`, then save.
4. Open the published HTTPS URL after GitHub Pages finishes deploying.

## Find information
Use the **Search** button or Ctrl/⌘+K from anywhere. Quick Find searches lesson drills and practicums, glossary tasks, business assignments, casebook debriefs, and cocktail recipes; results show matching context. Select a business topic or glossary term to jump directly to it. With an empty search, shortcuts take you to key sections. The search index and large recipe catalog load only when needed.

## Learning content
Includes 120 open lessons with supervised field practicums and saved four-dimension performance self-reviews; 94 glossary entries, each with a distinct practical task; 25 business topics, each with a unique evidence artifact and three observable checks; 100 quiz questions linked to ten field drills; 15 open-response shift scenarios with a five-dimension response rubric; a pairing experiment worksheet; and a 12-route beverage atlas with 200 cocktails and family-specific execution labs. Practice scores record learning—not certification or workplace authorization.

## Privacy and limitations
Progress, notes, planning values, rubric marks and inventory remain in the current browser's `localStorage`; they are **not encrypted, uploaded or synced**. Export a backup before clearing browser data or switching devices, and protect it because it can contain personal notes. Do not store passwords, payment details, credentials or sensitive guest/staff information.

This is a static, single-user study tool—not audited inventory/accounting software, legal/medical/accounting advice, or a food-safety system. Exercises do not replace venue SOPs, current local law, required certifications or qualified professional guidance. Follow official local requirements and authorized workplace procedures. The Atlas is same-origin and is not a security sandbox; GitHub Pages does not provide this project with custom security headers.
